# ʿUrf — Local Customs under Maqasid

ʿUrf (عرف) means recognised local custom. In this project, **urf is the only channel for local traditions**.

## Hierarchy

```
Maqasid (global, non-negotiable objective function)
        ↓
ʿUrf (local customs — tunable per country)
        ↓
Must not contradict Maqasid
```

## What belongs under urf

| Tradition | Status in OSD |
|-----------|---------------|
| Halacha | **ʿUrf** — local custom for communities/countries that use it |
| Liberal constitutional practice | **ʿUrf** — country-tunable |
| Human-rights instrument uptake | **ʿUrf** — local practice under Maqasid |
| Development-economics norms | **ʿUrf** — local practice under Maqasid |

Halacha is **not** a second global scoring framework. It falls under urf.

## Halacha as urf → Maqasid

| Halakhic custom (urf) | Maps to Maqasid |
|-----------------------|-----------------|
| pikuach nefesh | hifz_al_nafs (life) |
| tzedek | adl (justice) |
| tzedakah | hifz_al_mal (property/welfare) |
| kavod habriyot | karamah (dignity) |
| dina demalkhuta dina | shura (legitimate authority) |
| bal tashchit | la_darar (non-harm) |

## Validation rules

1. Every urf mapping must name a Maqasid principle.
2. If a local custom contradicts Maqasid, it is **rejected** — not scored.
3. Countries may tune urf weights and expressions; they may not override Maqasid red lines.
4. Government expenditure still maps to **Maqasid**, not to urf labels alone.
